# Smart Expense Tracker (Python)

A console-based Expense Tracker application built using Python. This project helps users manage daily expenses with features like adding, viewing, searching, deleting, and analyzing expenses.

---

## Features

- Add new expenses with amount, category, description, and date
- View all saved expenses
- Search expenses by category
- Delete specific expense records
- Category-wise expense summary
- Persistent data storage using CSV file
- Input validation using exception handling

---

## Technologies Used

- Python
- OOP (Object-Oriented Programming)
- File Handling (CSV)
- Exception Handling
- datetime module

##  How to Run

1. Clone the repository:
   git clone https://github.com/your-username/expense-tracker.git

2. Navigate to the project folder:
   cd expense-tracker

3. Run the program:
   Add Expense
   View Expense
   Exit
   Category Summary
   Search Expense
   Delete Expense
